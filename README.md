## Updating the CV

The CV is generated from LaTeX. Edit `docs/cv/Adityan.tex`, then rebuild the PDF the site serves:

```bash
tectonic docs/cv/Adityan.tex && mv docs/cv/Adityan.pdf public/cv/Adityan.pdf
```

`tectonic` is installed via Homebrew (`brew install tectonic`). The template is [sb2nov/resume](https://github.com/sb2nov/resume).
